Matches upstream release cycles to the latest SBOM of each code repo branch. By default every tracked dependency version is listed, whatever its EoL date: past, future or not published. Both dates are inclusive. Leave a date blank for an open range; any date drops versions whose EoL date is unknown.

Update EoL data downloads the current release cycles from the official endoflife.date API, generated from the endoflife-date/endoflife.date GitHub project. The result is shown on Imports; a failed update keeps the previous dates.
